# Кредитный скоринг (FastAPI + CatBoost)

Веб-форма: вводите данные заёмщика -> получаете шанс одобрения, кредитный балл,
график влияния признаков (SHAP) и список «что хорошо / что мешает».

## Запуск

```bash
pip install -r requirements.txt
# положите credit_risk_dataset.csv рядом с train.py
python train.py            # создаст model.cbm и meta.json
uvicorn main:app --reload
```

Откройте http://127.0.0.1:8000

## Что изменено относительно ноутбука

- `fillna(df[col].mean)` был без скобок (подставлялся метод, а не число) - теперь заполнение медианой.
- Удалены выбросы (возраст > 100, стаж > 60 лет).
- `loan_percent_income` считается автоматически как сумма кредита / доход.
- Для приложения обучается одна модель (с отложенной выборкой и early stopping, AUC печатается).

## API

`POST /api/score` - JSON с полями заёмщика, ответ: `chance`, `score`, `factors[]`.
Документация: http://127.0.0.1:8000/docs
